FAQ

Fair questions.

Do agents write all your code?

No. Agents are tooling, not a substitute for judgment. Every change still goes through the review and tests I've used since shipping to hundreds of millions of users — a diff merges only when it's right.

What is agent orchestration, concretely?

Running many agent sessions as one system: spawn, supervise, steer, review, recover. I build the harness itself — my ZCode chat integration and Hermes Agent harness are in review on agent-orchestrator.

Can I see the work?
